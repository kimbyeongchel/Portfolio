LostRuins 재설계 문서

졸업 작품 LostRuins의 플레이어·멀티플레이 구조를 C++ 권위 서버와 Unity 클라이언트로 다시 설계한 기록입니다.

1편 · 기술 포스트모템원본이 왜 2~3초 늦었는지, 점프가 왜 굼떴는지 등 문제 진단 11가지 2편 · 재설계서무엇이 가장 크게 바뀌는지, 구조와 클래스 다이어그램, 전체 소스, 측정값 3편 · 해설서서버 개념을 비유·애니메이션·시뮬레이션으로 설명, 재검증 기록, 코드 한 줄씩 해설 4편 · 직업 재설계전사·궁수·창술사·힐러 코드, 원본에서 찾은 버그, 스킬 타임라인, 테스트, 고민 노트

소스 코드와 테스트는 GitHub 저장소에 있습니다.
